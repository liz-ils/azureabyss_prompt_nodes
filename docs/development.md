# 開発環境

このノードはWindows上のComfyUIで動作確認します。

- ComfyUI: Stability Matrixで導入した環境
- GPU: NVIDIA推奨
- Python: ComfyUIが使用するPython環境
- Git: 変更履歴の管理とGitHubへの公開に使用

## 動作確認

1. このリポジトリを`ComfyUI/custom_nodes/azureabyss_prompt_nodes`へ配置する
2. ComfyUIを再起動する
3. 起動ログに読み込みエラーがないことを確認する

外部パッケージは使用しないため、現時点では`requirements.txt`はありません。
