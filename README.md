# AzureAbyss Prompt Nodes

ComfyUI向けのプロンプト処理カスタムノードです。

## 開発状況

本リポジトリは『ComfyUI カスタムノード開発解説』のサンプルコードです。
`main`は書籍で扱う完成版、`develop`は章ごとの開発途中を記録します。

## ノード

- `Add Prompt Prefix`: 文章へ接頭辞・接尾辞を追加する基本ノード
- `Prompt Formatter`: 空白を整え、接頭辞・本文・接尾辞を結合するノード

## Gitブランチ

- `develop`: 書籍の章ごとの開発履歴
- `main`: 動作確認済みの公開版

## インストール

このフォルダをComfyUIの`custom_nodes`へ配置し、ComfyUIを再起動してください。
